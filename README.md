# Programming Hero Assignment-5

## 📝 Project Name
Programming Hero Assignment-5

## 📖 Description
This project is a React-based application built to practice modern frontend technologies. It showcases developer technology cards where users can **select** and **remove** cards dynamically. The project also demonstrates responsive design, component-based architecture, and interactive UI features.

## 🛠️ Technologies Used
- React  
- DaisyUI  
- Tailwind CSS  
- JSON  
- React Icons  
- React Toastify  
- Vite  

## ✨ Features
1. **Card Selection & Removal**  
   - Users can select developer technology cards and remove them dynamically.  

2. **Sticky Navbar**  
   - A responsive sticky navigation bar is implemented for smooth user experience.  

3. **Interactive Notifications**  
   - Integrated React Toastify to show user-friendly notifications when actions are performed.
